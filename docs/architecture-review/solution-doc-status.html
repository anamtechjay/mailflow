4Top gaps, ranked

If you fix only a few things, fix these — most blocking first.

1
A2Typed error taxonomy missing entirely keystone

No Auth/Permanent/Transient classes; the pipeline only counts retry attempts. Foundational — both B3 and B4 depend on it. Do this first.

2
B4Throttle storm crashes the run

When "slow down" retries are exhausted the error propagates all the way up and aborts everything. No 5xx retry, no progressive backoff, no concurrency cap.

3
B1Size guard fails open on unknown size

An unknown size becomes 0 and sneaks past the limit, so oversized/unknown emails slip through instead of being safely rejected before download. Low effort, high impact.

4
A4No fingerprint on the outgoing event; docs claim exactly-once

The idempotency_key is computed internally but never put on the wire, and the docs promise exactly-once — the opposite of the real at-least-once. A breaking wire-contract change if deferred past V1.

5
A5No way to verify a "new mail" ping is genuine

Gmail has zero verification; push ingestion is currently unauthenticated. V1 needs Gmail OIDC-JWT (signature/audience/issuer).

6
B3"Not found / gone / garbled" not treated as permanent

404 is silently skipped, 410 is retried forever, garbled data is retried wastefully. Depends on A2 landing first.

7
A8SecretProvider can't save a rotated token

No on-refresh persistence callback — a renewed OAuth refresh token is forgotten, so the next run silently breaks. (Multi-tenant/DWD intentionally out of V1.)

8
A7No conversation-thread ID on the clean email

Gmail threadId is unmapped, with no subject-line fallback — consumers can't reliably group conversations.

9
B5No shared HTML→text fallback

HTML-only emails come out with blank plain text. Since V1 is plain-text-only, this is what makes the output usable.

A9 (store erasure/encryption) was previously ranked here but is now dropped from V1 scope. C1 (Outlook expiry clamp) and A1 (Outlook wake-rewire) are deferred with the rest of the Outlook fast-follow.

Bottom line. mailflow is a genuinely usable Gmail polling library today (injectable filters & cleaners, 11 passing tests, a real second-provider proof in D1). It is not yet V1 because the freeze-now contract surface is only ~32% done — shipping without it forces painful rewrites on consumers later. Recommended path: land A2 first, then B4 + B1 for live safety, then freeze A4 · A5 · A7 · A8 · A11 before declaring V1.
